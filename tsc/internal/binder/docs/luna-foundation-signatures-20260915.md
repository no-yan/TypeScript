## 新規・削除する関数

| 操作 | 署名・対象 | 理由 |
| --- | --- | --- |
| 追加 | `func (b *Binder) newFlowData(flags ast.FlowFlags, data *ast.Node, antecedent *ast.FlowNode) *ast.FlowNode` | newFlowNodeEx の通常 AST と合成 payload の引数を分離。FlowNode.Data 専用 |

| 削除 | `setFlowNode`、`setReturnFlowNode` | 静的に対象が分かる既存呼出箇所から対応する Store setter を直接呼ぶ |
| 削除 | 未使用になった生成 Binder 専用 helper | 生成元と生成物から同時に除く。使用中の既存生成 getter の `(ref, kind)` は維持 |

上表以外の署名変更・追加が必要になったら、目的と呼出元を進捗記録へ書き、基本規約内で解決する。`bind(node, kind)`、`bindKind`、全関数への kind 中継は今回追加しない。
